# 引言（初稿）

> 用于《小白学人工智能》期末大作业。定位：CityGreen 城市无人农场 BP 第 4.2 节「世界模型」模块的一个可运行实现。
> 写作原则：只承诺做得到的，明确边界，不夸大。

---

## 1. 城市农业的约束

城市农业与规模化大田农业在空间形态上存在本质差异：地块面积小、空间分散、边界不规则、作业空间受限。现有无人农场实践——无论是中国科学院伏羲农场的数据驱动决策体系，还是华南农业大学罗锡文院士团队的水稻全程无人化，抑或极飞科技的超级农场——其技术路线均以大田场景为设计前提，依赖大型农机或高度集成的专业化设备，难以直接迁移到城市小地块。

CityGreen 提出的应对方式是"边缘作业群 + 云端群体智能"：以低成本、小型化、模块化的无人设备（小型无人机群、无人车群、物联网传感器、智能水槽）作为边缘作业单元，以云端的多智能体系统作为决策中枢，通过"云端智能决策—边缘群体协同—现场自主作业—数据实时反馈—云端持续学习"的闭环，使有限能力的单个设备通过协作承担复杂农业任务。

在这一架构中，**世界模型承担"执行前推演"的职责**：它学习"农场环境状态 × 农事动作 → 未来状态"的转移动力学，使系统能够在真正执行前排演"若这样做，会发生什么"，从而支撑反事实推演、作业预验证与资源调度。

## 2. 问题的提出

然而，把世界模型放进真实的无人农场闭环，存在三个具体缺口。

**第一，缺动作条件。** 现有面向视频的自监督预测工作大多只回答"接下来会发生什么"，而不回答"如果我这样做会怎样"。前者是观测预测，后者才是决策所需。BP 中世界模型的定义明确包含"农事动作"作为输入，但公开数据与多数方法并不提供动作信号。

**第二，缺可靠的动作条件数据。** 真实场景下采集带动作标注的飞行数据成本高、风险大；公开的无人机数据集（如 VisDrone）仅有被动观测，不含动作、不含位姿，无法直接用于动作条件预测的训练与评估。

**第三，缺有效的评估方式。** 在持续性主导的场景中，全图级别的 IoU 会被大量静止区域稀释，一个"未来等于现在"的平凡基线即可获得较高分数，无法判别模型是否真正学到了动力学。

## 3. 本文的工作

本文不试图构建完整的农场世界模型，而是聚焦其中一个前置环节：**无人机飞行层的动作条件预测**。

选择这一环节的理由是：飞行安全是所有空中作业的前提。植保、巡检、运输等农事动作，都建立在"飞行器能够预判并避开即将被占据的区域"这一能力之上。若飞行层的预测不成立，上层任何农事决策都无从执行。

具体地，本文：

1. **构建一个仿真数据采集管线**，在 Unreal Engine 中同步记录相机画面、位姿、动作指令与占据真值，为动作条件预测提供带因果结构的数据；
2. **训练一个 JEPA 式的小规模世界模型**，以 8 帧观测与候选动作作为输入，预测未来 1 秒的占据分布；采用 EMA 目标编码器与 VICReg 正则抑制表征坍缩；
3. **将预测接入经典分层规划框架**：全局路径由 A\* 依据静态地图生成，世界模型仅在飞行途中对局部路径做修正，从而把"世界模型的价值"与"全局规划的价值"解耦；
4. **以对照实验量化该价值**：在同一全局路径下，比较"用当前帧判断安全性"与"用世界模型预测安全性"的碰撞次数差异。

## 4. 边界

本文的工作有明确边界，需在阅读结论时一并考虑：

- **纯仿真**。所有实验在 Unreal Engine 中完成，未进行真机或半实物验证；
- **无真值动作以外的传感**。不包含 IMU 噪声、通信延迟、风扰等真实扰动；
- **单机、短时域**。预测时域为 1 秒，不涉及多机协同与长时域规划；
- **不涉及农事动作**。本文只建模飞行动作，灌溉、施肥、采摘等农事层的动作条件预测是后续工作。

这些限制来自课程周期与算力条件，而非方法本身的要求。
